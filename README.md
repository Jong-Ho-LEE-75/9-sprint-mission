# Discodeit

[![codecov](https://codecov.io/gh/Jong-Ho-LEE-75/9-sprint-mission/branch/main/graph/badge.svg)](https://codecov.io/gh/Jong-Ho-LEE-75/9-sprint-mission)

Discord-like 메시징 애플리케이션 (Spring Boot 3.4.0 + Java 17)

## 빌드 및 실행

```bash
# 테스트 실행
./gradlew clean test

# 애플리케이션 실행
./gradlew bootRun

# Docker Compose로 실행
docker compose up -d
```
